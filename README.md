# 📊 Automated Sales Data Pipeline & Power BI Dashboard

## 📌 Project Overview

This project demonstrates an automated sales data pipeline built for **practice and portfolio purposes**.

The workflow collects sales information through Google Forms, stores the responses in Google Sheets, processes and transforms the data using Make.com, and connects the cleaned dataset to Power BI for analysis and visualization.

An automated email notification is also included to demonstrate how new records can trigger notifications.

## 📊 Power BI Dashboard

The Power BI dashboard provides an overview of the sales data, including:

- 💰 Total Revenue
- 📈 Average Revenue
- 📉 Minimum Revenue
- 📦 Total Quantity
- 🧾 Number of Orders
- 🛍️ Revenue by Product
- 📍 Revenue by Location
- 📅 Revenue over Time

## ⚙️ Automation

When a new sales record is submitted through the Google Form, the response is captured in Google Sheets and processed through Make.com.

The data is cleaned and transformed before being added to the cleaned sales dataset.

The cleaned dataset is connected to Power BI for reporting and visualization.

An automated email notification is also generated when a new record is processed.

## 🧹 Data Cleaning & Transformation

The automation processes incoming sales records and prepares the data for analysis.

This includes:

- Cleaning incoming data
- Transforming data
- Calculating required values
- Adding processed records to the cleaned dataset
- Preparing the data for Power BI reporting

## 📧 Email Automation

The workflow includes an automated email notification that is triggered when a new sales record has been successfully processed.

This demonstrates how data workflows can be connected to business notifications without requiring manual intervention.

## ⚠️ Data Disclaimer

**The data used in this project is fictional/sample data created solely for learning, practice, and demonstration purposes.**

It does not represent real customers, businesses, transactions, or financial information.

The Google Form responses and sales records were created as test data to demonstrate the functionality of the automated workflow.

## 🎯 Project Purpose

The purpose of this project is to demonstrate how **data collection, data transformation, automation, reporting, and email notifications** can be connected into one workflow.

This project showcases practical skills in:

- Data Analysis
- Data Cleaning
- Data Transformation
- Workflow Automation
- Data Visualization
- Business Reporting
